方式二：

文件管理器 带 smb 协议的,可以使用windows局域网共享，共享文件夹。或者使用支持smb协议的PC工具来进行文件PC和AndroidTV之间的文件传输。

方式三：

adb 命令，打开开发者模式使用。安装apk ，输入长文本（重点）

  1. 打开电视机开发者模式，usb调试
  2. 电视和电脑处于同一个局域网
  3. 打开电视网络，拿到ip地址。
  4. 电脑命令行输入：
   adb connect 电视ip:5555
   adb install 路径.apk
   adb shell input text 输入长文本

开启adb之后，也可以使用PC端的屏幕投屏。使用鼠标操作 Escrcpy
